# Project Guidelines & Rules

## 1. Deployment & Git Workflow
- Setiap ada perubahan/fitur yang selesai dikerjakan, **wajib** melakukan commit dan push ke repository Git (`git push origin main`) agar perubahan otomatis ter-deploy dan muncul di **Vercel**.

## 2. Database
- Database utama project ini terhubung dan dikelola di **Supabase** (konfigurasi dan helper function ada di [`supabase.js`](./supabase.js)).
